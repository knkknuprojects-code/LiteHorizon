# Історичні документи Horizon

У початковому ZIP зберігався великий україномовний `README.md`, який після
підготовки публічної редакції перенесено до `DEVELOPER_GUIDE_UK.md` без
переписування його змісту. Він відображає стан і термінологію експортованого
проєкту, містить команди для розробника, а не лише для новачка.

Файли `DEVELOPMENT_PLAN.md`, `PHASE_*_PLAN.md`, `RUNNING.md` і `API_REFERENCE.md`
із зовнішніх Sources не були автоматично оголошені чинною специфікацією цієї
версії: частина описує попередні фази, а частина потребує регенерації за
поточним вихідним кодом. Матриця в `paper/EVIDENCE_MATRIX.md` перелічує їх як
історичні джерела, але не приписує новим модулем старих результатів.
