# Paper and software relationship

The research software in this repository accompanies the 2026 manuscript:

*LiteHorizon: An Experimentally Inspectable, Resource-Aware Architecture for
Automated Horizon-Scanning Support*

**Manuscript authors (as provided):** Emil Nasirov, Volodymyr Taranukha,
Oleksandr Marchenko, and Anatoly Anisimov.

The manuscript's reported studies are labeled **E1–E5**, with an additional
small **D1** demonstration. See [EVIDENCE_MATRIX.md](EVIDENCE_MATRIX.md) for the
relationship between described experiments, available source-code modules, and
historical reports supplied outside this repository.

## Availability

- No DOI or publisher landing page is asserted here. The repository URL and
  citation metadata should be updated after publication and verified approval.
- The source DOCX versions are **not** committed in this release candidate,
  pending permission review and selection of the canonical published version.
- Externally supplied WoS/Scopus records, full production model outputs,
  historical model/prompt checkpoints, and some run logs are not in the code export.
- Scientific findings should be read as within-corpus and configuration-dependent
  calculations, not as independently validated detection of emerging developments.
